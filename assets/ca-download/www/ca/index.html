HaLOS device trust

This device secures its web services with its own certificate authority (CA). Install the CA in your operating system's trust store once, and the browser security warnings disappear for every service on this device.

Download the HaLOS CA certificate

In your operating system's trust store this CA appears as HaLOS Device CA. Newer devices also show this device's hostname, this device, in parentheses — handy when you manage several HaLOS devices and need to tell their certificates apart (or remove a stale one).

Installing the certificate is not enough on its own. Every platform needs a second, explicit "trust this for websites" step after the file is installed — Apple, Android, and desktop browsers all keep installation and trust separate. The per-platform steps below call out exactly where that step is.
macOS
  1. Download halos-ca.crt (the button at the top does the same).
  2. Double-click the downloaded file. Keychain Access opens and adds the certificate to the System keychain (choose System if it asks which keychain); enter an admin password if prompted.
  3. It's installed but not yet trusted. In Keychain Access, select the System keychain, find HaLOS Device CA under Certificates (on newer devices it reads HaLOS Device CA (this device)), and double-click it.
  4. Expand Trust and set Secure Sockets Layer (SSL) (or When using this certificate) to Always Trust. Close the window and authenticate. macOS keeps install and trust separate — without this step the warnings stay.
  5. Quit and reopen your browser.

On macOS the raw certificate is the reliable path: a certificate delivered by a configuration profile is not added to Keychain Access and cannot be granted SSL trust there, so the profile install (used on iPhone/iPad) does not help on a Mac.

iPhone / iPad (iOS & iPadOS)

Download the install profile

  1. Tap Download the install profile above in Safari and allow it. iOS shows Profile Downloaded. Use Safari — other browsers can't hand the profile to iOS.
  2. Open Settings → General → VPN & Device Management, tap the HaLOS Device CA profile (newer devices name it HaLOS Device CA (this device)), then Install (enter your passcode). The profile is unsigned, so iOS marks it "Not Verified" — expected for your own device.
  3. Then open Settings → General → About → Certificate Trust Settings and turn on the toggle for the HaLOS CA. iOS 17/18 require this separate toggle — installing the profile alone does not trust it for websites.
Advanced: install the raw certificate instead
  1. Download halos-ca.crt in Safari. iOS usually saves it to the Files app instead of prompting.
  2. Open the Files app and tap the downloaded halos-ca.crt. iOS asks whether to allow the certificate — allow it, then it appears under Settings → General → VPN & Device Management.
  3. Install it from there, then enable it under Settings → General → About → Certificate Trust Settings. The install profile above avoids this Files-app detour — prefer it.
Android
  1. Tap Download above to save halos-ca.crt.
  2. Open Settings, search for cert, and choose CA certificate under Install a certificate. Searching jumps straight to the right screen — the manual path (Security → Encryption & credentials) is several taps deep and varies by vendor.
  3. Accept the warning and pick the downloaded halos-ca.crt.

Android trusts user-installed CAs in browsers only, not in apps — this is an Android design decision. You will get a green lock in Chrome or Brave; native apps still show warnings.

Linux (Debian / Ubuntu)

System trust store (Chromium, Chrome, curl, most apps):

  1. Download halos-ca.crt.
  2. Install it: 
    sudo cp halos-ca.crt /usr/local/share/ca-certificates/halos-ca.crt
sudo update-ca-certificates
  3. Restart Chromium or Chrome.

Firefox keeps its own certificate store: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import, select halos-ca.crt, and trust it for websites.

Windows
  1. Download halos-ca.crt.
  2. Double-click it and choose Install Certificate → Local Machine (accept the admin prompt).
  3. Select Place all certificates in the following store → Trusted Root Certification Authorities, then finish.
  4. Restart your browser.

Chrome and Edge use the Windows certificate store automatically. Firefox keeps its own store: either set security.enterprise_roots.enabled to true in about:config (Firefox then trusts the certificate you just installed), or import halos-ca.crt directly as described in the Linux section.

Once the CA is trusted, every service on this device validates cleanly. Decline the install and you can still click through the browser warning on each service — but you will see it again for every new port.
