HaLOS device trust

This device secures its web services with its own certificate authority (CA). Install the CA in your operating system's trust store once, and the browser security warnings disappear for every service on this device.

Download the HaLOS CA certificate

Installing the certificate is not enough on its own. Every platform needs a second, explicit "trust this for websites" step after the file is installed — Apple, Android, and desktop browsers all keep installation and trust separate. The per-platform steps below call out exactly where that step is.
macOS
  1. Click Download above. halos-ca.crt lands in Downloads.
  2. Double-click the file. Keychain Access opens — add it to the login keychain.
  3. In Keychain Access, find the HaLOS CA under Certificates and double-click it.
  4. Expand Trust and set When using this certificate to Always Trust. Close the window and enter your password when prompted. This is the mandatory trust step — adding the certificate without it leaves the warnings in place.
  5. Quit and reopen your browser.
iPhone / iPad (iOS & iPadOS)
  1. Tap Download above and allow the download. iOS shows Profile Downloaded.
  2. Open Settings → General → VPN & Device Management, tap the downloaded profile, then Install (enter your passcode).
  3. Then open Settings → General → About → Certificate Trust Settings and turn on the toggle for the HaLOS CA. iOS 17/18 require this separate toggle — installing the profile alone does not trust it for websites.
Android
  1. Tap Download above to save halos-ca.crt.
  2. Open Settings → Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate (the exact path varies by vendor).
  3. Accept the warning and pick the downloaded file.

Android trusts user-installed CAs in browsers only, not in apps — this is an Android design decision. You will get a green lock in Chrome or Brave; native apps still show warnings.

Linux (Debian / Ubuntu)

System trust store (Chromium, Chrome, curl, most apps):

  1. Download halos-ca.crt.
  2. Install it: 
    sudo cp halos-ca.crt /usr/local/share/ca-certificates/halos-ca.crt
sudo update-ca-certificates
  3. Restart Chromium or Chrome.

Firefox keeps its own certificate store: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import, select halos-ca.crt, and trust it for websites.

Windows
  1. Download halos-ca.crt.
  2. Double-click it and choose Install Certificate → Local Machine (accept the admin prompt).
  3. Select Place all certificates in the following store → Trusted Root Certification Authorities, then finish.
  4. Restart your browser.

Firefox on Windows also uses its own store — import the certificate as described in the Linux section.

Once the CA is trusted, every service on this device validates cleanly. Decline the install and you can still click through the browser warning on each service — but you will see it again for every new port.
